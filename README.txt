SMARTSTUDY - STUDENT PERFORMANCE & STUDY PLANNER
Course: 2026CSAE100 - Computational Thinking and Programming

FILES
1. smartstudy.py       Main Python program
2. students.csv        Sample demonstration records (you may edit/replace these)
3. class_report.txt    Created automatically by menu option 6
4. Project_Report.docx Project documentation
5. SmartStudy_Presentation.pptx Presentation

HOW TO RUN
1. Keep smartstudy.py and students.csv in the same folder.
2. Open this folder in VS Code.
3. Open Terminal and run: python smartstudy.py
4. Select an option from the menu (1 to 7).

NOTES
- The sample names and marks are fictional demonstration data.
- Marks must be between 0 and 100.
- The program uses only Python's built-in csv and os modules.
- The project does not use machine learning or advanced AI.
